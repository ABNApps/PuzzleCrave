# PuzzleCrave

The website for **PuzzleCrave: Offline Puzzles**, eight puzzle games with 600 levels, for Android.

Visit it at <https://abnapps.github.io/PuzzleCrave/>

- [Privacy Policy](https://abnapps.github.io/PuzzleCrave/privacy.html)
- [Support](https://abnapps.github.io/PuzzleCrave/support.html)
- [Promo video on YouTube](https://youtu.be/q4k5SKgtN8I)

## Versions

Each app version has its own self-contained pages and assets, and a switch at the top of the home page moves between them.

| Version | Status | Pages | Assets |
|---|---|---|---|
| 2.0.0 | Coming soon | `index.html`, `support.html` | `assets/` |
| 1.1.0 | On Google Play now | `v1.1.0/index.html`, `v1.1.0/support.html` | `v1.1.0/assets/` |

The latest version lives at the root, because Google Play links there. `privacy.html` is shared by every version: it is the same policy the app shows.
